# Sticker Studio

Утилита для превращения видео в видеостикеры Telegram. Русский интерфейс, предпросмотр, шкала с кадрами и выбор отрезка перетаскиванием границ или вводом времени.

## Онлайн-версия — без установки

**[Открыть Sticker Studio](https://grislytoe.github.io/stickers/)**

Открывайте ссылку с компьютера, телефона или планшета в современном браузере с WebAssembly. Node.js и включённый домашний компьютер не нужны. Конвертация выполняется на вашем устройстве, видео не отправляется на GitHub или другие серверы.

При первом выборе видео загружается движок FFmpeg (около 24 МБ), затем браузер может использовать свой HTTP-кеш. Ограничение онлайн-версии: 100 МБ и 10 минут на исходный файл. На мобильных устройствах выбирайте короткие исходники: доступная память и скорость зависят от устройства. Во время конвертации держите вкладку открытой. Есть кнопка отмены.

Веб-версия находится в `docs/`, публикуется GitHub Pages из `main:/docs` и не использует серверный API. Используется проверенная сборка `@ffmpeg/core` 0.11.0: протестированные сборки 0.12.x падают при VP9-кодировании. Вложенный service worker `coi-serviceworker` добавляет заголовки COOP/COEP для SharedArrayBuffer. При первом открытии страница может автоматически перезагрузиться для активации изоляции. Нужен современный браузер с WebAssembly, Service Worker и SharedArrayBuffer; старые и некоторые встроенные браузеры не поддерживаются. Если исходный формат не проигрывается браузером, движок создаёт MP4 для предпросмотра. Сохранение результата использует обычную загрузку файла браузером.

Локальный просмотр веб-версии для разработки: `node scripts/preview-pages.mjs`, затем `http://127.0.0.1:3211`. Локальный вариант ниже использует нативный FFmpeg и работает быстрее на больших исходниках.

## Запуск на Windows

1. Установите [Node.js 22 или новее](https://nodejs.org/).
2. Скачайте репозиторий и запустите `start.bat`.
3. При первом запуске автоматически загрузится FFmpeg. Откроется `http://127.0.0.1:3210`.

Если браузер открылся раньше сервера, обновите страницу. Окно консоли нужно оставить открытым; Ctrl+C останавливает приложение.

Альтернативный запуск из терминала (Windows, Linux x64, macOS Intel/Apple Silicon):

```sh
node scripts/setup.mjs
node server.mjs
```

Зависимостей npm нет. Вместо загрузки можно использовать собственный FFmpeg с кодеками libvpx-vp9 и libx264, указав полный путь в переменной `FFMPEG_PATH`. Порт меняется переменной `PORT`.

## Использование

1. Перетащите видео или выберите файл (до 250 МБ и 10 минут).
2. Выберите отрезок от 0,1 до 3 секунд: двигайте рамку, тяните её края или задайте точное время. Стрелки на выделенной границе меняют время на 0,05 с, Shift+стрелка — на 0,5 с.
3. Оставьте исходные пропорции либо включите круг. Круг вырезается из центра, углы становятся прозрачными. Положение круга пока не регулируется.
4. Нажмите «Создать стикер», затем «Сохранить .webm».
5. Отправьте результат [@Stickers](https://t.me/Stickers) **как файл/документ**, чтобы создать или дополнить видеостикерпак.

Экспорт: WebM, VP9, без аудио, длинная сторона ровно 512 пикселей, длительность не более 3 секунд, частота до 30 кадров/с. Приложение проверяет фактический размер и повторяет кодирование с меньшим качеством, затем при необходимости снижает частоту кадров до 24/18/12. Выдаётся только файл не больше 256 000 байт. Если даже этого недостаточно, приложение попросит выбрать более короткий отрезок.

Требования: [официальная документация Telegram](https://core.telegram.org/stickers/webm-vp9-encoding).

## Приватность и хранение

Сервер слушает только `127.0.0.1`. Обработка происходит на вашем компьютере, видео не отправляются на внешние сервисы. Интернет нужен при первоначальной загрузке FFmpeg и для перехода в Telegram. Интерфейс не использует внешние шрифты, аналитику или CDN.

Исходники, предпросмотры и результаты временно хранятся в `.data/`; каталоги старше 24 часов удаляются при следующем запуске. Для немедленного удаления закройте сервер и удалите `.data/` вручную. Каталог исключён из Git. После перезапуска сервера загрузите видео заново.

## Проверки

```sh
node --test
```

Интеграционная проверка создаёт настоящее тестовое видео со звуком и проверяет оба режима экспорта: VP9, разрешение, длительность, отсутствие аудио, лимит размера и альфа-канал (прозрачный угол / непрозрачный центр).

FFmpeg не включён в репозиторий. Установщик загружает сборку 6.1.1 через [ffmpeg-static](https://github.com/eugeneware/ffmpeg-static); лицензии и исходники FFmpeg доступны у [поставщика сборки](https://www.gyan.dev/ffmpeg/builds/) и на [ffmpeg.org](https://ffmpeg.org/legal.html).
